# Landmark feature UI references

The two generated v2 boards and their prompts supplied visual direction: existing parent form theme, Nunito typography, blue actions, soft panels, child guide and warm map colours. Generated with the built-in image tool.

The initial ordered-walk concept was superseded by the user’s clarification. Implementation uses **independent landmarks**, no walk records, landmark sequence, connected path or assumed route. Child practice matches a landmark photo to its map location rather than asking what comes next. Treat the sequence questions in the concept boards as historical proposals only.

For implemented behaviour see `../../SCREEN_FLOW.md`. Demo photo assets and their full generation prompts are in `../../../mobile/assets/landmarks/`.
